# colitu/.github

Organisation-wide files for [github.com/colitu](https://github.com/colitu):

- `profile/README.md` — the organisation profile page.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`,
  `.github/ISSUE_TEMPLATE/` and `.github/pull_request_template.md` — default
  community files, used by every Colitu repository that does not have its own.
