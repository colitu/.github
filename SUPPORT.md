# Getting help

GitHub issues are for bugs and feature requests in the code. For everything
else:

- **Account, subscription, payment or connection problems:**
  <https://colitu.com/support> or support@colitu.com
- **Guides and common questions:** <https://docs.colitu.com>
- **Is the service down?** <https://status.colitu.com>
- **Security problems:** security@colitu.com (see [SECURITY.md](SECURITY.md))

Please never post your e-mail, password, subscription link, keys or IP address
in a public issue.
