# Contributing to Colitu

Thanks for helping. Bug reports, translation fixes and focused pull requests
are welcome in every public Colitu repository. A repository's own
`CONTRIBUTING.md`, if it has one, takes precedence over this file.

## Before you start

- **Security problems:** do not open an issue; follow [SECURITY.md](SECURITY.md).
- **Account, payment or connection problems:** these are handled by support at
  <https://colitu.com/support>, not on GitHub.
- For larger changes, open an issue first so we can agree on the approach.

## Pull requests

- Keep each pull request to one change, and describe what it fixes and how you
  tested it.
- Follow the style of the surrounding code; do not reformat unrelated files.
- Add or update tests for behaviour changes; CI must pass.
- Do not commit secrets, signing keys, server addresses or personal configuration.
- The apps speak Russian, English and Turkish; a new user-facing string needs
  all three.

## Licence and trademarks

By contributing you agree that your contribution is published under the
licence of the repository you contribute to (GPL-3.0 for the apps, MIT for
vpn-lab). The Colitu name and logo are not covered by these licences: if you
publish your own build, use your own name and logo.

## Code of conduct

All Colitu projects follow the [Code of Conduct](CODE_OF_CONDUCT.md).
